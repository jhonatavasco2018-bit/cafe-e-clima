# Café & Clima — projeto Android

Projeto Android Kotlin com workflow GitHub Actions para compilar APK.

## Conteúdo inicial
- Tela inicial Café & Clima
- Link para cotação diária Coabriel
- Esqueleto de seção de previsão do tempo
- Workflow automático que compila e publica o APK como Artifact no GitHub Actions

## Como compilar
Envie o conteúdo desta pasta para o repositório GitHub `cafe-e-clima`, na branch `main`.
Depois vá em **Actions**, abra o workflow **Build Android APK**, e baixe o artifact `Cafe-e-Clima-apk`.

**Nota:** esta versão é um esqueleto inicial. As cotações numéricas e clima ainda não estão integrados com APIs; a cotação Coabriel abre a página oficial. É preciso evoluir a integração antes de considerar os dados automatizados.
